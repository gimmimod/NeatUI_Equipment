# NeatUI Equipment

Your character in 3D, surrounded by everything they are wearing, with a Wardrobe for saved outfits. A NeatUI panel on the edge of the CleanUI inventory, for Project Zomboid Build 42.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3790656296
- Mod ID: `NeatUI_Equipment`
- Author: Gimmi

## Layout

- `workshop/` is the mod exactly as it is uploaded: `workshop.txt`, the preview and `Contents/mods/NeatUI_Equipment/`, with one folder per game build it supports.
- `art/` holds the cover and the images for the Steam page.
